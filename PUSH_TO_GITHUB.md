# 🚀 Instrucciones para Subir a GitHub

Tu repositorio local está **100% listo**. Solo necesitas estos 2 pasos:

---

## ✅ PASO 1: Crear Repositorio en GitHub (2 minutos)

1. Abre: https://github.com/new
2. Llena el formulario:
   - **Repository name**: `lolowebdev`
   - **Description**: "Generador de landing pages cinematográficas con scroll Apple-style, React 19, GSAP 3, cero placeholders"
   - **Public** (elige para que sea público)
   - **NO inicialices con README** (ya lo tienes)
3. Click **"Create repository"**
4. ¡Listo! Tendrás una URL como: `https://github.com/TU-USUARIO/lolowebdev`

---

## ✅ PASO 2: Conectar y Subir (30 segundos)

Reemplaza `TU-USUARIO` y copia estos comandos en tu terminal:

```bash
cd ~/lolowebdev

git remote add origin https://github.com/TU-USUARIO/lolowebdev

git branch -M main

git push -u origin main
```

**Ejemplo real** (si tu usuario es "john-doe"):
```bash
git remote add origin https://github.com/john-doe/lolowebdev
git branch -M main
git push -u origin main
```

---

## 🎉 ¡LISTO!

Tu repo estará en:
```
https://github.com/TU-USUARIO/lolowebdev
```
