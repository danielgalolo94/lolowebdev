# Contribuir a LOLOWEBDEV

¡Las contribuciones son bienvenidas! Aquí está cómo:

## Cómo Contribuir

1. **Fork** el repositorio
2. **Crea una rama**: `git checkout -b feature/tu-feature`
3. **Commit**: `git commit -m "feat: descripción de cambios"`
4. **Push**: `git push origin feature/tu-feature`
5. **Abre un Pull Request**

## Ideas para Contribuir

- 🎨 Nuevos estilos de estética
- 🧩 Componentes adicionales
- 🔌 Integraciones (CMS, Payment, Analytics)
- 📝 Ejemplos de casos de uso
- 📚 Mejoras en documentación
- 🐛 Bug fixes y optimizaciones
- ✨ Micro-animaciones avanzadas

## Guías

- Mantén los prompts documentados
- Añade ejemplos de uso
- Actualiza el CHANGELOG.md
- Testea en múltiples navegadores
- Sigue el style guide existente

## Reportar Bugs

Abre una issue con:
- Descripción clara
- Pasos para reproducir
- Resultado esperado vs actual
- Screenshots/videos si aplica

## Contacto

Abre una discussion para preguntas generales.

¡Gracias por contribuir! 🚀
