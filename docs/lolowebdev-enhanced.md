## 🎬 FASE 2: VIDEO-FIRST ARCHITECTURE

### 2.1 Premium Scroll Checklist (Non-Negotiable)

- [ ] **Lenis Smooth Scroll** — Smooth wheel scrolling con easing personalizado
- [ ] **Navbar Scroll-to-Pill Transform** — Full-width → Centered pill en scroll
- [ ] **Magnetic Snap-Stop** — Scroll pausa rítmica en aparición de cards
- [ ] **4+ Animation Types** — Nunca repetir animación consecutivamente
- [ ] **Staggered Reveals** — Label → Heading → Body → CTA (no simultáneo)
- [ ] **Direction Variety** — Left, right, up, scale, clip (entrada desde diferentes ángulos)
- [ ] **Massive Typography** — Hero 12rem+, headings 4rem+, marquee 10vw+
- [ ] **Horizontal Marquee** — Oversized text 12vw+ deslizando en scroll
- [ ] **Counter Animations** — Números contando desde 0, nunca estáticos
- [ ] **Canvas Circle-Wipe** — Hero revela via clip-path: circle() al scrollear
- [ ] **CTA Persists** — Última sección visible permanentemente (data-persist="true")
- [ ] **Frame Speed 1.8-2.2** — Animación completada al 55% scroll

### 2.2 Arquitectura HTML Premium

```html
<!-- Estructura garantizada -->
1. Loader (progress bar + brand)
2. Header (navbar fixed, scroll-aware)
3. Hero Standalone (100vh, solid bg, word-split)
4. Canvas Container (fixed, frame-by-frame rendering)
5. Dark Overlay (fixed, 0.88-0.92 opacity)
6. Marquee Sections (fixed, oversized text)
7. Scroll Container (800vh+ total)
   - Content sections (data-enter, data-leave, data-animation)
   - Stats section (counters animados)
   - CTA section (data-persist="true")
```

### 2.3 GSAP + Lenis Choreography

```javascript
// Animación coordinada multi-tipo
- Slide Left/Right: Transform X
- Fade In/Out: Opacity
- Scale In: Transform scale
- Clip Path: Reveal progresivo
- Stagger: Secuencial con delay
- Magnetic Snap: ScrollTrigger pause
```

### 2.4 Canvas Frame Rendering

```javascript
// Video to scroll-experience conversion
1. Extract frames (MP4/MOV → WebP @ 150-300 frames)
2. Preload first 10 (fast paint)
3. Load remaining en background
4. Render frame-by-frame indexed on scroll %
5. Scale: 0.85 (sweet spot visibility)
```

## 🎨 FASE 3: DOMINIO-AWARE GENERATION

### 3.1 SaaS B2B
**Estética**: Tech Premium  
**Secciones**: Hero (product demo video) → Features (tab + video) → Testimonios (video clips 5-8s) → Pricing (3D video comparison) → CTA  
**Typography Scale**: h1: 4rem, h2: 2.5rem, body: 1rem  
**Animation**: Slide + Fade, staggered reveals  

### 3.2 Agencia Creativa
**Estética**: Lujo Moderno  
**Secciones**: Hero (motion graphics reel 15s loop) → Archive (cada proyecto con video) → Manifiesto (subtitle animations) → Testimonios (client video clips) → Contact  
**Typography Scale**: h1: 5rem (serif), h2: 2rem (serif italic)  
**Animation**: Clip-path reveals, horizontal scrolls, 3D rotations  

### 3.3 Startup Pre-Seed
**Estética**: Minimalismo Oscuro  
**Secciones**: Hero (abstract motion graphics) → Features (GSAP + video parallax) → Beta Signup (video testimonios early adopters) → Roadmap (timeline con video milestones)  
**Typography Scale**: h1: 3.5rem (mono), h2: 2rem (mono)  
**Animation**: Minimal motion, focus on content, counter animations  

### 3.4 E-commerce Luxury
**Estética**: Energía Vibrante / Monocromía  
**Secciones**: Hero (product video 360°) → Gallery (video showcase per product) → Social Proof (customer unboxing clips) → CTA  
**Typography Scale**: h1: 4.5rem, h2: 2.5rem, body: 1rem  
**Animation**: Smooth zooms, parallax depth, staggered product reveals
